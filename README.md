## Operating Philosophy

I think in products, systems, and distribution, not just code.

Good software should make hard things feel usable. The best technical work often disappears into a clear workflow, a trusted transaction, a faster team, or a product people can actually understand.

I care about turning ambiguity into shipped products, building for the messy edges of real markets, using AI where it removes friction, and designing financial tools that respect how people actually earn, move, and manage money.
